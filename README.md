# 13mm-Rocket
A 13mm rocket that is fully 3d printed. 
This project is a part of Hack CLub Star Dance, and it is in the hardware project catagory. As a result, all that will be in this Repo is photos of the build/design process and the 3d models for the rockets.

## Hardware
The rockets only consist of 5 parts, the 3d printed body, nosecone, and spacer, a 5mm bolt used as a counterweight, and a 13mm rocket motor, specifically the Estes A10 - 3T
